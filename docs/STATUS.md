## 二、本轮修复（1.0.1 → 1.0.3）

| # | 问题 | 修复 |
|---|---|---|
| 1 | **楼梯爬不上二层**：台阶只铺到 `step + 1`，而 `offset % 6` 永远到不了 6；上层楼板与天花板也没开洞，走到一半就撞头 | 楼梯改为「表面在 `offset = step + 1`，表面以下实心、表面以上 2 格净空」；楼梯井会切开本子层天花板与上一子层地板；最后一列台阶正好落在 `offset = SUB_H` 的上层地板上 |
| 2 | 楼梯选址用错层：`roomRects(..., 0)`、`regionAt(...)` 和「上层是否空旷」都按第 0 层或 `layer + 1` 判定 | 全部改用当前 `layer`；楼梯带逐列校验房间 / 柱子 / 区段边界；装饰（草簇、碎屑、板条箱）不再抢占第一级台阶 |
| 3 | **二层区段之间不连通**：通道只在 `offset < 6` 打开 | 两侧都是两层区段时，在 `7 ~ 10` 再开一条上下对齐的通道，中间保留 `offset = 6` 的楼板；通高区段维持原规则 |
| 4 | **群系不随层**：`sectorBiomeAt(x, z)` 固定按第 0 层；维度 JSON 的 `layer_height` 还是 18，而生成器是 12 | `sectorBiomeAt(x, z, layer)` 按当前层取区段；`layer_height` 改为 12；`AQUILA` 直接映射到 `aquila_sector`（原逻辑会随机落到仓库 / 积水群系） |
| 5 | 闪烁现象自带一套 `LAYER_H = 18`、`SUB_COUNT = 3`，与生成器 12 / 2 不一致 | 改为直接引用 `Level1ChunkGenerator` 的常量，扫灯层号与真实楼层对齐 |
| 6 | `BiomeTint` 仍按 288 高推断 L1 层高 18；F3 调试信息固定显示第 0 层区段 | 层高改为 12；调试信息按玩家 Y 取层号与区段 |
| 7 | 缺少资源自检，模型 / 贴图 / 语言键 / 层高漂移只能靠人眼 | 新增 `tools/selfcheck.py`：JSON 解析、层高不变式、模型与贴图引用、`en_us`/`zh_cn` 键对齐，共 2836 项 |
| 8 | **闪烁只扫到一部分灯**：扫描步长固定 3，而各区灯距是 2/5/6/7/8，衔尾段的灯坐标对 3 取模后永远不会命中 | 改为逐格扫描两个子层天花板（每个区块 2×256 格），覆盖全部灯位；用 `MutableBlockPos` 避免逐格分配对象 |
