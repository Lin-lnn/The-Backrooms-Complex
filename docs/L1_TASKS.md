## 四、设计备忘

- L1 **不使用** BiomeTint：贴图为实色，`BiomeTint` 只服务 L0。
- `LAYER_H = 12`，`SUB_H = 6`，`SUB_COUNT = 2`；`SUB_COUNT * SUB_H == LAYER_H` 是子层逻辑的前提。
- 区段判定基于 96 格哈希区，与群系无关；优先级见 `regionAt()`。
- 小径迷宫连通性由「交叉点必通 + 每格四面墙各开 2 格门」保证，改动后必须重跑洪水填充验证。
