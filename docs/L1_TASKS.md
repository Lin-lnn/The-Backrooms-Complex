## 三、设计备忘

- L1 **不使用** `BiomeTint`：贴图为实色；`BiomeTint` 的 L1 分支只用于手动放置的 L0 方块。
- `SUB_COUNT * SUB_H == LAYER_H` 是子层逻辑的前提；`selfcheck.py` 会校验。
- 区段判定基于 96 格哈希区、按 `layer` 参与哈希；优先级见 `regionAt()`。
- 楼梯只在本层内爬升 6 格，因此「上层是否空旷」查的是同一个 `layer` 的上一子层，而不是 `layer + 1`。
- 两层区段的通道在 `offset 1~5` 与 `7~10` 各开一条，中间 `offset 6` 的楼板保留。
- 小径迷宫连通性由「交叉点必通 + 每格四面墙各开 2 格门」保证，改动后必须重跑洪水填充验证。
