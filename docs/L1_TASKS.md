1. **A1~A5**（让 7 个区段真正出现，这一步收益最大）
2. **B1~B3**（分层与门/灯对齐）
3. **C1 + D1~D2**（跃金段板条箱是文中核心玩法）
4. **C2~C5**（其余区段特色，可逐个来）
5. **E1~E4**（收尾）
