# Level 1 参考参数：住宅区地下车库

> 用途：给生成器提供「现代地下车库」的真实比例，替代凭感觉定的常量。
> 参考：后室 Level 1 条目（[Backrooms Archive Unit](https://backroomsarchiveunit.wikidot.com/level-1)、[BWIKI](https://wiki.biligame.com/backrooms/Level_1)）、停车库结构标准（[TRB Bulletin 195](https://onlinepubs.trb.org/Onlinepubs/hrbbulletin/195/195.pdf)）、MC 建筑参考（[mc-mod schematics](https://www.mc-mod.net/schematics/modern-parking-garage-structure/)）。

## 一、真实停车库尺寸（米）

| 项 | 常见值 | 说明 |
|---|---|---|
| 车位宽 | **2.4 ~ 2.5** | 欧洲 2.5，北美 2.7 |
| 车位长 | **5.0 ~ 5.5** | 垂直停车 |
| 双向车道 | **6.0** | 单向 3.5 ~ 4.0 |
| 结构柱网 | **8.0 × 16.0** | 8 跨两排车位 + 中间车道 |
| 沿立面柱距 | **5.4 ~ 8.1** | 受梁高限制 |
| 净高 | **2.1 ~ 2.7** | 最低 2.1（限高杆 2.0）|
| 楼板厚 | 0.3 ~ 0.4 | |
| 柱截面 | **0.4 ~ 0.6 见方** | 常刷 1.0 ~ 1.2 m 高的警示带 |
| 坡道坡度 | 12 ~ 15% | 短坡道可 16% |
| 照明 | 50 ~ 75 lux | 荧光灯约每 **8 m** 一盏 |
| 地面标线 | 宽 0.1 | 白色 |

## 二、换算成方块（1 m ≈ 1 格）

| 项 | 真实 | 方块 |
|---|---|---|

| 车道宽 | 6.0 | **6** |

## 三、我们当前 L1 的参数 vs 真实值

| 项 | 当前代码 | 真实值 | 偏差 |
|---|---|---|---|
| `PILLAR_STEP` | **16** | 8 ~ 16 | ✅ 在真实区间 |
| 柱子截面 | **2×2** | 1×1 | 略大，但更醒目 ✓ |
| `LAYER_H` | **12**（两层 6/层）| 4 | 偏大，但为了两层结构可接受 |
| 单层净高 | **4**（6 − 地板 − 天花板）| 2.4 ~ 2.7 | ✅ 接近 |
| 灯距 | 2 / 5 / 6 / 7 / 8（按区段） | 8 | 部分区段偏密 ✓ |
| 车位标线 | **无** | 有 | 缺失 ✗ |
| 楼梯 | 6 格爬 6 格（100% 坡度）| 12 ~ 15% | **极陡** ✗ |

## 四、建议的「真实感」改造（按收益排序）

| # | 改造 | 参数 | 收益 |
|---|---|---|---|
| 1 | **加密柱网** | `PILLAR_STEP` 48 → **16**；柱截面 4×4 → **2×2** | 立刻从"巨型大厅"变成"车库" ✅ 已完成 |
| 2 | **地面车位标线** | 每 3 格一条白色细线（用 `white_concrete` 或地毯）| 一眼即知是停车场（未做） |
| 3 | **楼梯放缓** | 6 格高需要 **18 格**水平距离（15% 坡度），可折返 | 不再像梯子（未做） |
| 4 | 警示带 | 柱脚 1 格（已有 `concrete_warning_pillar`）| ✅ 已完成 |
| 5 | 灯距 | 按区段 2~8 格 | ✅ 已按区段接线 |

## 五、后室 Level 1 的氛围要点（文字来源）

- 无限延伸的**地下停车场**：混凝土柱、荧光灯、潮湿地面
- **宜居地带**：物资、板条箱、可躲避
- **仓库区**（`warehouse_aisles`）、**天鹰段**（`aquila_sector`）
- 远处有机器嗡鸣
- 非欧几里得：走远后回头，地形已经不同

## 六、可直接落地的常量建议

```java
/** 结构柱网间距（格）。真实车库 8~16，取 16 保证可玩性与辨识度。 */
public static final int PILLAR_STEP = 16;

/** 柱子半径：0 = 1x1，1 = 3x3。真实柱截面 0.5 m，取 1 格。 */
public static final int PILLAR_RADIUS = 0;

/** 车道宽度（格）。真实 6 m。 */
public static final int AISLE_WIDTH = 6;

/** 车位标线：每 3 格一条。 */
public static final int BAY_LINE_STEP = 3;
```
